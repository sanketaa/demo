# Git Branching Practice

A small historical repository used to practice the basic Git and GitHub workflow.

## Background

This is not a software application. It contains a few text files and commits created while learning how to initialize a repository, create and modify files, work with a feature branch, commit changes, and publish history to GitHub.

The commit history includes a feature-branch exercise and later updates to `test.txt`, making the repository useful as a simple record of early version-control practice.

## Concepts Practiced

- Creating a Git repository
- Adding and tracking files
- Writing commits
- Creating a feature branch
- Keeping a visible change history
- Pushing work to GitHub

## Files

| File | Purpose |
| --- | --- |
| `README.md` | Explains the repository |
| `feature.txt` | Represents a change introduced through a feature exercise |
| `test.txt` | Simple tracked file used for commit practice |
